# docs/ — 프로젝트 문서 및 산출물 (총괄: 이오리)

```
docs/
├── md/                  # 작업 내용 누적 기록 (마크다운, 담당자별 작성)
├── 프로젝트_진행일지/   # 일별·팀원별 진행 내역
├── 산출물/              # 주요 산출물 원본
└── pdf/                 # 완료 문서 PDF 보관
```

## 산출물 작성자 지정

| 산출물 | 작성자 |
|--------|--------|
| 요구사항 정의서 | 홍기흥 |
| 화면 설계서 | 박미금 |
| AI 모델 성능 평가서 | 김모란 |
| 데이터 분석 보고서 | 이오리 |
| 시스템 설계서 | 홍기흥 |
| 프로젝트_발표자료.pptx | 이오리 (총괄) |

## 브랜치 전략

- `main` — 배포 브랜치 (Render·Netlify 자동 배포)
- `dev` — 통합 브랜치
- `feature/기능명` — 개인 작업 → PR 리뷰 → 조장 최종 승인 후 병합
